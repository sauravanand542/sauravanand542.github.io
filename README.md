# sauravanand542.github.io

Static portfolio for [Saurav Anand](https://github.com/sauravanand542). GitHub Pages serves this repository from the `main` branch at the root (`/`).

There is no build step. `index.html`, `styles.css`, and `main.js` are the site. `.nojekyll` tells GitHub Pages to publish those files as-is.

Star counts on the project cards were read from the GitHub API on 24 September 2026.
