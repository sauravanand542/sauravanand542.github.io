About

Saurav Anand publishes on GitHub as @sauravanand542. The public repositories are Python, Jupyter Notebook, and R projects in data science and machine learning, plus bioinformatics and AI tooling.

They include an RNA-seq pipeline that tests genes with OLS regression, notebooks on job listings, a Fetch Rewards SQL assessment, and Lending Club and Yelp analyses. AI work covers a FastAPI restaurant host built with OpenAI and Twilio, and codebase-md, a command-line tool that writes project-context files for AI coding assistants.
